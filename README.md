# AX-9 Legal Page

Statische, zweisprachige GitHub-Pages-Seite für **AX-9: Broken Relay**.

Vor der Veröffentlichung:

1. Die Platzhalter für die Anschrift in `imprint/index.html` und `privacy/index.html` ersetzen.
2. Den Ordnerinhalt in das gewünschte öffentliche GitHub-Repository hochladen.
3. Unter **Settings → Pages** als Quelle den Branch `main` und den Ordner `/ (root)` wählen.
4. Die direkten URLs testen, insbesondere `/privacy/` für App Store Connect.
